# moysoft assets repository

This repository is **read-only**.

It exists solely to host **public assets** (icons, metadata, app files) that are consumed by  
https://www.moysoft.com at runtime.

## ❌ No contributions

- Issues are disabled
- Pull requests are not accepted
- Discussions are disabled

Any issues or pull requests opened anyway will be ignored and closed.

## ℹ️ Purpose

This repository is intentionally public so the moysoft website can:
- fetch app metadata
- load icons and assets
- display store content dynamically

It is **not** intended for collaboration or external use.

## 🔒 Maintenance

All changes are made internally by the repository owner only.

Thank you for understanding.
